# Quix.io Animated Video

An animated video presentation based on the Quix.io homepage, designed for LinkedIn (1:1 aspect ratio).

## Features

- **Duration**: ~30 seconds (loops automatically)
- **Aspect Ratio**: 1080x1080px (1:1 for LinkedIn)
- **Colors**: Exact Quix.io brand colors
  - Primary Blue: #0064FF
  - Purple: #BD2EFF
  - Orange: #FF7828
  - Background: #222229
- **Font**: Geist (from Google Fonts)
- **Technology**: HTML/CSS/JavaScript with GSAP animation library

## Animation Sequence

1. **Scene 1** (0-5s): "Take control of your test data" - Main headline with scale animation
2. **Scene 2** (5-10s): "All your data in one place" - Icon boxes converging
3. **Scene 3** (10-15s): "Real results in real time" - Animated wave visualization
4. **Scene 4** (15-20s): "Join test and config data" - Data points connecting
5. **Scene 5** (20-25s): "Open data formats via API" - Text with pulse effect
6. **Scene 6** (25-30s): "QUIX" logo reveal with tagline

## How to Use

1. **Open in Browser**: Simply open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge)

2. **Recording Your Screen**:
   - Use screen recording software (OBS, QuickTime, Windows Game Bar, etc.)
   - Set recording area to 1080x1080px if possible
   - The animation loops automatically, so you can record as many takes as needed
   - Record for 30 seconds to capture one full loop

3. **Tips for Best Results**:
   - Use fullscreen mode (F11) for clean recording
   - Ensure your browser window is exactly 1080x1080px for perfect quality
   - The animation starts automatically when the page loads
   - Refresh the page to restart the animation

## Customization

The animation uses GSAP (GreenSock Animation Platform) for smooth, professional animations. All timing and effects can be adjusted in the `<script>` section of the HTML file.

## Browser Compatibility

Works in all modern browsers that support:
- CSS Grid and Flexbox
- CSS Animations
- ES6 JavaScript
- GSAP 3.x
